## Customization

To customize the website:

### Colors
Edit the CSS variables in `styles.css`:
```css
:root {
    --primary-blue: #0052CC;
    --dark-blue: #003D99;
    /* ... other colors ... */
}
```

### Contact Form
Update the email address in `script.js` (line ~75):
```javascript
const mailtoLink = `mailto:your-email@example.com?subject=...`;
```

### Content
Edit any text directly in `index.html` sections
